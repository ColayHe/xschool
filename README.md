# X学院研发评审级原型

兴智教育 App、SCRM、传承后台与营地执行工作台的一体化交互原型。

当前版本重点覆盖：

- 家长端与营员端融合
- 兴智教育登录页的营员登录入口
- 家长授权、家庭邀请码与营员首次绑定
- X学院服务资格、课程、营期、预约与审批
- 营地签到、任务、异常、成长证据与营后报告
- 研发评审全流程导览

## 本地启动

电脑需要安装 Node.js，然后在项目目录运行：

```powershell
node server.cjs
```

浏览器访问：

```text
http://127.0.0.1:4173/?v=42
```

点击顶部“导览中心”，可以按业务链路逐步查看页面、正常流程、异常情况和权限边界。

## 目录说明

- `index.html`：原型入口
- `app.js`：页面数据与交互逻辑
- `styles.css`：主要界面样式
- `tour.css`：导览中心样式
- `assets/`：课程封面与图片资源
- `server.cjs`：本地静态服务
